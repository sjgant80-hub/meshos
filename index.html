Honest limits (v1) — Bluetooth mesh (BitChat) is not reachable from a browser (Web Bluetooth cannot advertise; needs a native bridge). LoRa needs an ESP32 bridge over WebSerial — detected but nothing is connected until you plug one. WebRTC works today with paste-signalling (no server, some friction). A Reticulum JS port does not exist yet. The relay backhaul is off unless you point it at a relay you trust. Not audited — do not carry state secrets. The loopback echo node exists so every layer is testable right now on one device. v1 is for the technically-adjacent; the path to v2 is use, feedback, hardening.

MIT · source & mutation gate — the codec, capability lattice and witness chain are the gated kernel.mjs verbatim (injected, CI-diffed). Pure client-side: install it, cut the internet, it still works.
